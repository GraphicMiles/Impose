# Impose Agent Atlas brand assets

Agent Atlas is a small AI ant carrying a disproportionately large boulder: small agents, massive work.

All production artwork in this folder is generated raster imagery. No SVG production mark is included.

## Usage

Keep clear space around the mark at least equal to one ant-eye diameter. Use the full-colour square mark for digital avatars and product icons. Use the black or white transparent one-colour file for clothing, stickers, stamps, and single-ink applications. Use the 16 percent variants over photographs or campaign layouts as watermarks.

The transparent merchandise files are 2400 px tall and suitable for direct-to-garment mockups and ordinary digital print runs. Confirm the printer's required dimensions and resolution before final manufacturing.
